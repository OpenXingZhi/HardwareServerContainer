** Check Device
QR, HF, and UHF are opened by hardware-proxy. The kRPC routes are fixed:
=/qr=, =/hf=, =/uhf=, and =/card=. Do not put those paths in the tablet config.

#+begin_src sh
  lsusb
#+end_src

Defaults are QR =0525:A4AC= interface 1, HF =FFFE:0091= interface 0, and UHF =03EB:2421= interface 0.
Override them with =QR_VID=, =QR_PID=, =QR_INTERFACE=, =HF_*=, and =UHF_*= on the hardware-proxy service.

[[file:mqtt-io/config.yml]] is the runtime file for the optional mqtt-io profile.
It must keep =stream_modules: []=. An old copy will claim the same USB devices.
